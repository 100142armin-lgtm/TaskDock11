# TaskDock 11 (Windows 11 超级扩展任务栏与智能应用坞)

> 解决 Windows 11 任务栏应用开太多放不下被隐藏、且无法自由拖宽多行显示的核心痛点。

---

## ✨ 核心特性

1. **零崩溃、非侵入式轻量架构**
   * 不修改系统核心文件，不注入 `explorer.exe`，Win11 任意版本推送大更新也能安稳运行。
   * 内置底层原生动态库自适应预挂载引擎，彻底杜绝单文件环境下的依赖丢失异常。
2. **Alt+Tab 工业级窗口精准捕获**
   * 自动过滤后台幽灵进程、输入法浮窗、小组件后台等。
   * 智能提取浏览器标题（剥除冗余后缀，高亮显示核心标签页名称）。
   * 全局多显示器应用窗口汇总，实时监控增删变化。
3. **原生级交互控制与双击回缩**
   * **单击应用：** 未激活则唤出置顶，当前活动窗口再点则最小化（完全对标 Win11 原生体验）。
   * **活动高亮：** 当前正在前台的窗口底部带有 Win11 标志性发光高亮条。
4. **智能状态角标**
   * **会议中状态：** 腾讯会议/Zoom/Teams 等会议中状态呈现高科技翡翠绿「● 会议」微标。
   * **未读消息提示：** 微信/钉钉/飞书等通讯软件有新消息或新通知时显示脉冲红「●」或消息计数。
5. **智能折行与多行 Dock 排版（方案 2）**
   * 支持自由调节「每行图标数」（6 ~ 24 个/行，默认 12 个）。
   * 超出设定数量自动折行展示，完美解决应用过多溢出屏幕边缘的痛点。
6. **自由拖拽排序与手机级文件夹堆叠合并（模式 C）**
   * 随意拖拽应用改变排序；
   * 把一个应用拖到另一个应用上即可自动**合并为一个文件夹/分组**，点击展开子应用列表，极度节省桌面空间。
7. **极简外观与 16 款精选全色系色调**
   * 面板纯粹极简，仅保留把手与应用图标，设置与控制全面整合进暗黑磨砂玻璃右键菜单中。
   * 提供 16 款预设质感色球（黑曜石、星舰深蓝、极光墨绿、炽火暗红等）与自由 HEX 调色。
8. **应用重命名、临时隐藏与一键恢复**
   * 支持右键为任意应用自定义显示名称；
   * 支持临时隐藏特定应用（不关闭后台运行），并支持一键恢复全部显示。
9. **团队使用与应用内无感智能升级**
   * 内置开机自启动开关；
   * 内置 GitHub Releases 自动检测与应用内一键下载覆盖升级，免去手动打开网页下载解压的繁琐流程。

## 🚀 启动与使用指南

### 1. 快速启动
在项目根目录双击独立绿色版：
`TaskDock11.exe`

### 2. 快捷操作
* **移动位置：** 按住左侧把手或者在浮动模式下直接拖拽空白处。
* **合并分组：** 将一个图标拖拽到另一个图标正上方松开。
* **解散分组：** 右键文件夹图标，点击【📂 解散此分组】。
* **自定义名称：** 右键应用图标，点击【✏️ 自定义应用名称...】。
* **临时隐藏：** 右键应用图标，点击【👁️‍🗨️ 在此面板中隐藏】。
* **恢复隐藏：** 右键空白处，点击【👁️ 恢复所有隐藏的应用】。
* **调色与偏好设置：** 右键空白处或图标，点击【⚙️ 外观与偏好设置...】打开控制台。

## 📦 团队 GitHub 托管与自动发布流程

1. 在 GitHub 上新建一个仓库（例如 `TaskDock11`）。
2. 在本地项目根目录初始化 git 并推送到仓库：
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit for TaskDock11"
   git branch -M main
   git remote add origin https://github.com/<你的用户名或团队组织>/TaskDock11.git
   git push -u origin main
   ```
3. 在软件右键【设置】中将 `GitHub Owner` 和 `GitHub Repo` 填入你的对应仓库名称。
4. 后续发布新版本时，在 GitHub Releases 创建一个 Release 并上传打包好的单文件 `TaskDock11.exe`，团队成员的客户端就会自动弹出新版本更新提示并一键跳转下载！
