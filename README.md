# TaskDock 11 (Windows 11 超级扩展任务栏与智能应用坞)

> 解决 Windows 11 任务栏应用开太多放不下被隐藏、且无法自由拖宽多行显示的核心痛点。

---

## ✨ 核心特性

1. **零崩溃、非侵入式轻量架构**
   * 不修改系统核心文件，不注入 `explorer.exe`，Win11 任意版本推送大更新也能安稳运行。
2. **Alt+Tab 工业级窗口精准捕获**
   * 自动过滤后台幽灵进程、输入法浮窗、小组件后台等。
   * 全局多显示器应用窗口汇总，实时监控增删变化。
3. **原生级交互控制**
   * **单击应用：** 未激活则唤出置顶，当前活动窗口再点则最小化（完全对标 Win11 原生体验）。
   * **活动高亮：** 当前正在前台的窗口底部带有 Win11 标志性发光高亮条。
4. **自由拖拽排序与手机级文件夹堆叠合并（模式 C）**
   * 随意拖拽应用改变排序；
   * 把一个应用拖到另一个应用上即可自动**合并为一个文件夹/分组**，点击展开子应用列表，极度节省桌面空间。
5. **四向停靠与三大屏幕并存模式**
   * 可停靠至 **上 / 下 / 左 / 右** 或 **自由浮动**；
   * **避让工作区模式（AppBar）：** 独占屏幕边缘，其它窗口最大化时绝不遮挡；
   * **始终置顶模式：** 悬浮在一切窗口最上层；
   * **智能自动隐藏：** 鼠标离开时自动滑出边缘收起。
6. **Win11 原生磨砂毛玻璃与高定制美学**
   * 支持亚克力（Acrylic Blur）毛玻璃特效；
   * 支持背景色拾取、透明度无级滑块调节、图标大小（28px~64px）滑块调节。
7. **团队使用与自动更新**
   * 内置开机自启动开关；
   * 内置 GitHub Releases 自动更新检测器，团队成员一键感知并升级。

## 🚀 启动与使用指南

### 1. 快速启动
在项目根目录运行或直接双击编译出的单文件绿色版：
```bash
dotnet run
```
或直接使用发布的单文件：
`bin\Release\net10.0-windows\win-x64\publish\TaskDock11.exe`

### 2. 快捷操作
* **移动位置：** 按住左侧把手或者在浮动模式下直接拖拽空白处。
* **合并分组：** 将一个图标拖拽到另一个图标正上方松开。
* **解散分组：** 右键文件夹图标，点击【📂 解散该分组】。
* **强制结束卡死程序：** 右键图标，点击【⚠️ 强制结束进程 (Kill)】。
* **调色与设置：** 右键空白处或点击右侧小齿轮 ⚙️ 打开设置面板。

## 📦 团队 GitHub 托管与自动发布流程

1. 在 GitHub 上新建一个仓库（例如 `TaskDock11`）。
2. 在本地项目根目录初始化 git 并推送到仓库：
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit for TaskDock11"
   git branch -M main
   git remote add origin https://github.com/<你的用户名或团队组织>/TaskDock11.git
   git push -u origin main
   ```
3. 在软件右键【设置】中将 `GitHub Owner` 和 `GitHub Repo` 填入你的对应仓库名称。
4. 后续发布新版本时，在 GitHub Releases 创建一个 Release 并上传打包好的单文件 `TaskDock11.exe`，团队成员的客户端就会自动弹出新版本更新提示并一键跳转下载！
